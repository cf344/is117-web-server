# IS117 Basic Web Server

This project is a basic web server I created for my IS117 class using Node.js and Express.

The server has a home page, an About page, and a 404 page for addresses that do not exist.

I also used Jest and Supertest to create automated tests to make sure the three routes work correctly.

## How to Run

1. Install Node.js.
2. Run `npm install` in the project folder.
3. Run `npm start`.
4. Open `http://localhost:3000` in a browser.

## Testing

Run `npm test` to check the three routes.

All three automated tests passed.
